The six safety layers
L1 Input guardNo localhost, private or raw IPs, odd ports or credentials in the URL.
L2 Action guard6 fixed action types; the element must exist, stay on site, and never be Delete/Pay/Buy.
L3 Browser guardNo off-site navigation; in safe mode no write requests; no service workers.
L4 Network guardNo direct internet. The egress proxy allows only the site and common CDNs.
L5 Secret guardZero secrets inside the sandbox. The AI key never enters it.
L6 Resource guardFresh container per stage, destroyed after; CPU, RAM, pid and time limits.
